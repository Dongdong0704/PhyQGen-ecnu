## 🎯 项目要解决什么

高中物理习题需要同时满足**物理规律正确、条件与答案一致、难度合适**等要求；涉及受力图、电路图等图示时，还要保证图文一致。教师自行编题和逐题核验耗时，而直接使用通用生成工具仍需仔细检查推理、单位、图示与解析。

PhyQGen 计划让教师输入知识点、题型、难度等要求，获得可检查、可修改的习题草稿。系统拟采用分工生成与校验的流程，提示疑点，由教师决定是否采用。详细边界见[问题定义与产品描述](docs/requirements/problem_definition.md)。

## 🔄 预期使用流程

`教师设定要求 → 生成题目、答案与解析草稿 → 检查物理逻辑和一致性 → 教师修改并确认`

首轮验证聚焦**文本题目、答案和解析**；图示生成与图文一致性检查是后续拟验证的方向。具体技术选型和功能范围将根据需求访谈、原型测试与课程进度调整。
