# PhyQGen 前端交互原型

在原 AQG Vue 3 前端基础上，按 `PhyQGen/docs` 中的教师出题流程实现。原项目文件没有改动。本目录可独立运行，无需数据库、Python 后端或模型密钥。

## 启动

Windows 双击 **启动原型.cmd**，会启动本地服务并打开浏览器。结束后可双击 **停止原型.cmd**。首次使用需要 Node.js 18+；当前电脑已准备好前端依赖。

也可在 PowerShell 中运行：

```powershell
cd "E:\AAA2026学习工作\智能教育软件工程实践\code\frontend"
npm ci        # 已有 node_modules 时可跳过
npm run dev
```

访问 <http://127.0.0.1:5173>。使用命令行启动时按 Ctrl+C 停止。端口固定为5173，如被其他服务占用会报错，不会悄悄换端口。

| 身份 | 用户名 | 密码 |
| --- | --- | --- |
| 教师 | teacher | Teacher123 |
| 管理员 | admin | Admin123 |
| 第二位教师，用于检查私有题库隔离 | physics_li | Teacher123 |

普通注册只创建教师账号。新教师题库为空，已有示例主要在 `teacher` 账号下。

## 推荐体验顺序

1. 教师登录，打开概览，了解题目数量与分布。
2. 打开“习题生成”，选知识点、年级、题型、认知目标、难度、C1～C6思维标签，设置1～5道、知识库与配图。
3. 创建任务，在生成页或“生成任务”查看每题进度；切换页面或刷新后仍可查看。
4. 打开草稿，查看题干、公式、答案、解析、配图与引用来源；在编辑窗口修改并预览，保存生成新版本。
5. 人工核验后点击“确认定稿”。缺少必需字段或要求的配图不能预览时会阻止确认。
6. 在题库搜索/筛选/评分，单题或勾选多题导出定稿TXT。修改定稿后会回到待审核，须确认新版本。
7. 原有优秀习题与讨论流程也保留；仅已确认且评分达到4星的题目进入演示广场。
8. 退出后切换管理员，体验教师账号维护、模型配置、知识库开关/演示重建、并发与轮次配置、维护日志。

“习题生成 → 流程演示选项”可切换：正常、批量部分失败、全部失败、配图失败、知识库未命中、检索异常、保存失败、调用超时。部分失败保留其他结果；保存失败的示例可查看与复制，但不能作为已入库定稿导出。

## 当前实现边界

- 页面、表单、编辑、图片上传预览、版本、人工确认、搜索筛选、TXT下载和管理操作实际可交互。
- 数据保存在当前浏览器 `localStorage`，刷新可恢复；不同浏览器、端口或清理站点数据后不会共享。
- 模型生成、RAG检索、自动校验、连接测试和索引重建采用明确标注的本地模拟。题目使用牛顿第二定律、简单串联电路、机械能守恒三组预置例题，不具备任意知识点实时出题能力；选择的教学标签也不代表模型已验证其适配性。
- 内部校验意见不向教师显示。任务完成与教师确认分别记录，教师编辑或定稿不会启动模拟生成。
- 登录与角色隔离用于原型流程演示，浏览器内含演示账号信息；接入真实后端时必须替换为服务端认证和授权。
- TXT保留LaTeX源文本、教学属性、确认版本及配图引用。引用本地图片时需同时保留文件/服务；上传图片使用完整data URL写入引用，TXT可能较长。

## 代码与验证

`frontend/src/prototype/` 是数据模型、预置例题、事务式本地保存及旧API适配层。`frontend/src/views/` 保留原项目页面组织；新增生成任务页，题库加入审核与版本。KaTeX、字体与示意图均在本地，无CDN依赖。

```powershell
cd frontend
npm run typecheck
npm run build
npm run preview -- --host 127.0.0.1 --port 4173
```

已固定 TypeScript 5.3.3，兼容原项目的 vue-tsc 1.8。浏览器验收脚本、截图和下载样例在 `frontend/output/playwright/`；验收记录见《验收记录.md》。系统构成、需求对照及后端迁移建议见《系统梳理与原型说明.md》。

清理 `127.0.0.1:5173` 的浏览器站点数据即可恢复种子数据，会同时清除本原型中自行创建的内容。
