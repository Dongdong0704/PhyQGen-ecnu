# PhyQGen：问题定义（第 1 周草案）

> 状态：待团队访谈与确认。下文以“物理习题生成”为项目名称所暗示的工作假设，不代表已验证的用户需求。

## 5W1H

| 维度 | 初步定义 | 待验证的问题 |
| --- | --- | --- |
| Who 谁 | 物理教师、助教是出题与审核者；学生是题目的使用者。 | 首批目标是哪个学段、课程与用户群？ |
| What 什么 | 提供物理题目草稿的生成、人工检查与导出流程。 | 需要哪些题型、答案解析和格式？ |
| Why 为什么 | 降低备题重复劳动，同时保持知识点与答案的准确性。 | 现有出题流程最费时的环节是什么？ |

| Where 何处 | 预期通过网页使用；部署环境尚未确定。 | 是否需要移动端、离线或校内网？ |
| How 如何 | 教师填写知识点、难度等约束，系统生成候选题；教师审核、修改后使用。 | 生成模型、题目校验、数据来源和隐私要求是什么？ |

## 首阶段拟验证的流程

1. 教师输入学段、知识点、题型和难度。
2. 系统返回题目、参考答案与解析草稿。
3. 教师检查物理正确性与表述，修改或拒绝草稿。
4. 仅将审核通过的题目用于教学。

## 首阶段验收候选标准

- 能完成一次从输入约束到获取候选题的演示。
- 每道候选题同时展示题干、答案与解析，并标明需要人工审核。
- 对缺失输入和生成失败给出可理解的提示。
- 用一组由教师确认的样例记录正确性问题与修复结果。

## 暂不承诺

自动发布未经审核的题目、真实学生数据处理、多模型性能指标和大规模部署；是否纳入后续迭代由团队确认。
