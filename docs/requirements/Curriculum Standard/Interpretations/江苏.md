# 江苏省高中物理教学要求分析报告

精简版  ·  考察深度与知识来源

## 一  文件定位与主要结论

《江苏省普通高中物理课程标准教学要求（修订版）》将课程标准细化为学习要求和教学建议，覆盖8个模块、26个二级主题，采用必修物理1、物理2及选修模块结构。核心要求是**掌握基本概念与规律，在限定情境中应用，并理解规律的形成、证据和社会意义。**

## 二  考察深度

考察深度包括知识掌握与思维运用：前者关注掌握程度，后者关注分析过程。下列两表分别列举知识要求和归纳思维要求；六类思维要求可共同出现，不是原文规定的等级。

### 1  知识领域举例

| 知识领域 | 代表要求与深度边界 |
| --- | --- |
| 运动与力学<br/>物理1、物理2 | 理解速度、加速度与牛顿定律，运用动能定理和机械能守恒。限定情境下要求定量应用；不要求用二次函数解复杂追及问题、求解三个及以上连接体问题或用弹性势能表达式解题。 |
| 电场与电路<br/>选修3-1 | 辨析场强、电势差、电功与电热，分析闭合电路与带电粒子运动。场强叠加限两个场，电路计算限简单混联；匀强电场中的粒子入射速度限平行或垂直于场强。 |
| 热学与微观物理<br/>选修3-3、3-5 | 用分子动理论和统计观点解释气体规律；了解能级，知道半衰期的统计意义，依据事实说明波粒二象性。气体实验定律、半衰期公式及德布罗意关系式不作定量计算；光电效应方程用于简单问题。 |

### 2  思维要求

| 思维要求 | 概念性总结 |
| --- | --- |
| 概念辨析<br/>与条件判断 | 把握概念的边界、区别与联系，识别规律的成立条件；根据研究对象和具体情境选择适用的分析方法。 |
| 图象、公式<br/>与过程相联系 | 联系文字、图象、公式等不同表示，将抽象信息转化为对物理过程的描述，保持各种表示的含义一致。 |
| 建模与<br/>合理简化 | 从实际对象中提取关键因素，作出合理假设和简化；说明模型的适用范围与局限，完成从现实问题到物理模型的转换。 |
| 证据推理<br/>与因果解释 | 依据观察、数据及物理规律，通过分析、归纳和推理解释现象及其因果关系；说明结论的依据，区分事实、假设与解释。 |
| 实验探究<br/>与方法迁移 | 围绕问题提出方案、控制变量、获取并处理数据，形成结论；将探究步骤和研究方法用于相关问题。 |
| 跨情境解释<br/>与综合评价 | 将原理和方法迁移至新情境，综合多个因素解释、比较和评价方案，形成有证据支持的判断。 |

### 3  考察深度总结

**知识掌握。**原文将知识要求分为了解、认识、理解和应用四个水平：从识别、描述，到把握联系、解释和判断，再到在新情境中运用规律。其中，“认识”介于了解与理解之间，“计算”列入理解水平。

三个知识领域的例子表明，整体要求是**掌握概念及其联系，在明确条件和范围内完成解释与基本应用。**不同知识点分别采用定性或定量要求；掌握程度应由行为动词、情境及括号限制共同确定，不能仅由计算量或公式数量判断。

**思维运用。**六类要求涵盖概念辨析、表示联系、条件判断、建模、证据论证、实验探究、情境迁移与综合评价，着重考察能否说明结论的形成过程、成立依据和适用条件。它们是相互关联的思维活动，不构成固定的递进等级。

计算量较小的问题也可能涉及较深入的思维活动。例如，气体实验定律不要求定量计算，仍要求作微观解释；散射实验不依赖复杂运算，仍要求说明证据与模型的联系。思维深度因而应结合推理、证据和迁移过程判断。

**操作与体验。**原文的技能要求包括独立测量、操作、制作或设计，并能进行调整或改进；体验要求涉及探究、交流和形成判断。多用电表使用、单摆测重力加速度及玻璃折射率测量等，应落实到操作与结果解释。实验表现、讨论和报告可作为体验目标的评价依据。

在知识掌握与思维运用的基础上，该文件还重视科学方法与社会责任的培养：引导学生初步体会极限思想，运用合理近似与估算处理物理问题；认识理想实验以实验事实为依据、通过合理推演探索物理规律的独立方法价值；结合技术应用、能源利用与环境问题，理解科技发展的社会影响，形成安全用电、节约能源和促进可持续发展的责任意识。这些要求体现了兼顾知识、方法与社会责任的育人导向。

## 三  知识来源与形成过程

知识的形成依据包括观察实验、定义与模型建构、数学推理，以及类比、守恒和统计等研究方法。下表概括其来源形式及代表载体。

| 来源或形成方式 | 来源形式与代表载体 |
| --- | --- |
| 观察与实验 | 现象观察和测量数据提供经验依据，如自由落体、电磁感应、散射实验和光电效应。 |
| 定义与概念建构 | 通过规定物理量的含义和表达关系形成描述工具，如速度、场强及电势的比值定义。 |
| 模型与科学抽象 | 从实际对象中提取主要特征，形成质点、点电荷、理想气体等研究模型。 |
| 数学表示与推理 | 由已有概念、规律及数学关系推演新的表达，如位移公式、动能定理和天体引力关系的形成。 |
| 类比与对称思考 | 借助已有规律的相似性或对称性提出研究设想，如静电力与引力的比较、“电生磁”与“磁生电”的探索。 |
| 守恒与统计思想 | 借助共同的不变量和大量对象的统计行为组织认识，贯通能量、电荷、动量及热现象等内容。 |

## 四  总结

这份教学要求以基本概念和规律为基础，要求在限定情境中运用知识，同时关注规律的形成、证据支持及物理学对技术与社会的影响。**计算的复杂程度有明确限制，实验、建模和论证仍是重要要求。**

学习评价应兼顾知识的含义与适用条件、规律的应用、推理的依据和实验过程，使知识掌握、思维运用与科学认识的形成相互联系。

资料依据：《江苏省普通高中物理课程标准教学要求（修订版）》，用户提供文件。知识水平与具体限制依据原文；思维分类、来源分类及总结为分析归纳。代表知识例子涉及物理1、物理2及选修3-1、3-3、3-5。
