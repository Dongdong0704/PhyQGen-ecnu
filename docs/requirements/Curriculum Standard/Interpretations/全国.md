# 全国普通高中物理课程标准分析报告

**2025年修订精简版 · 考察深度与知识来源**

## 一、文件定位与主要结论

《普通高中物理课程标准（2025年修订）》以物理观念、科学思维、科学探究、科学态度与责任四方面核心素养统领课程，设置必修、选择性必修和选修各 3 个模块。文件通过内容要求、教学提示、模块学业要求、学生必做实验和三级学业质量标准，将知识学习、思维发展、实验实践与价值责任连成完整体系。

## 二、考察深度

考察深度由知识内容、任务情境和核心素养水平共同决定。下列两表概括代表性课程领域与思维要求；思维分类为分析归纳，不是原文另设的等级。

### 1. 知识领域举例

| 知识领域 | 代表要求与深度边界 |
|---|---|
| **力学与相对论初步**（必修 1、必修 2） | 从质点模型、运动描述和牛顿定律发展到功与能、曲线运动、万有引力，并初步认识牛顿力学局限性。要求结合实验、图像和理论推导解决生产生活问题，重视模型条件、守恒观念和化繁为简。 |
| **电磁学与能源**（必修 3、选择性必修 2） | 学习静电场、电路、磁场、电磁感应、电磁振荡、传感器及能源利用。由基本现象和模型逐步发展到定量规律、装置分析与技术应用，强调实验探究、场的物质性、能量转化和科技社会影响。 |
| **振动、波与光**（选择性必修 1） | 用公式和图像描述简谐运动，通过实验认识波的传播、干涉、衍射、多普勒效应及光的折射和干涉。要求联系现象、模型、实验数据和实际应用，并理解波动规律之间的统一联系。 |
| **热学、原子与量子**（选择性必修 3） | 由分子动理论、气体规律和热力学定律认识宏观与微观联系，结合原子结构、原子核、光电效应和波粒二象性理解近代物理。重在证据、统计、模型、守恒和理论适用范围。 |
| **社会、技术与前沿**（选修 1 至 3） | 围绕物理学与社会变革、医疗、新能源、新材料、信息技术以及微观、高速和宇观世界开展专题学习，突出资料获取、调查研究、综合评价和开放性实践，为个性化发展提供空间。 |

### 2. 思维要求

| 思维要求 | 概念性总结 |
|---|---|
| **观念统整与条件判断** | 围绕物质、运动和相互作用、能量形成结构化认识；辨析概念、规律和模型的适用条件，从物理学视角描述、解释并预测现象。 |
| **模型建构与数学表征** | 从真实对象中提取关键特征，建构质点、点电荷、理想气体、圆轨道等模型；运用公式、矢量、函数图像和数量关系完成定性与定量分析。 |
| **推理、论证与质疑创新** | 依据事实与证据开展分析、综合、推理和论证，评价证据可靠性；对已有观点和结论提出合理或有依据的质疑，从不同角度形成见解。 |
| **实验探究与反思交流** | 经历提出问题、作出假设、设计方案、获取处理证据、形成解释、交流评估和反思改进的全过程，并能分析误差、撰写探究报告。 |
| **真实情境与综合实践** | 在生产生活、科技前沿和社会议题中选择并综合运用知识，完成解释、设计、评价或决策；任务难度随情境复杂性、新颖性和开放性提高。 |

### 3. 考察深度总结

#### 三级学业质量

- **水平 1：** 是高中毕业和合格性考试的依据，要求在熟悉情境中运用必修概念和规律作简单分析，依照已有方案获取证据并形成初步结论。
- **水平 2：** 要求覆盖力学、电磁学、光学、热学和原子物理学，在熟悉情境中选用恰当模型，在帮助下制订方案，评价证据并解释结果。
- **水平 3：** 要求在实际情境中综合运用多领域知识，自主完成模型转换和探究设计，准确论证、反思并提出有证据的质疑；等级性考试命题不超过该水平。

#### 知识与核心素养

知识不是孤立的考点清单，而是发展核心素养的载体。概念和规律要转化为物理观念，模型、推理和证据要转化为科学思维，实验过程要转化为科学探究能力，科技史、伦理、环境和国家科技成就则支撑科学态度与责任。

#### 实验与评价

课标列出 **21 个必做实验**，其中必修 12 个、选择性必修 9 个；合格性考试覆盖必修及相关 12 个实验，等级性考试覆盖必修、选择性必修及相关 21 个实验。实验要求不止于操作，还包括问题提出、方案设计、数据图像、误差分析、证据解释和交流反思。

#### 情境与难度

试题难度由核心素养水平、情境复杂性或新颖性、知识深度或广度共同形成。课标强调真实、多样、具有一定复杂程度和开放性的任务情境，要求抽取有代表性的核心概念、规律、思想和方法，避免把难度等同于计算繁琐。

#### 时代性与责任

课程联系航天、能源、材料、医疗、信息技术和人工智能，关注科学技术应用的效益、风险、伦理及环境影响。学生应理解科学本质，形成实事求是的态度、可持续发展责任和科技强国使命感。

## 三、知识来源与形成过程

课标将物理知识视为由观察实验、模型抽象、数学工具、推理论证、历史证据和社会实践共同形成的认识体系。下表概括其主要来源及代表载体。

| 来源或形成方式 | 来源形式与代表载体 |
|---|---|
| **观察、测量与实验** | 通过 21 个必做实验及大量内容实验获得事实与数据，如运动测量、力学规律、电阻率、电源参数、动量守恒、光的波长、气体规律和传感器制作。 |
| **定义与观念建构** | 经历速度、加速度、电场强度、电势、动量等概念的形成，将分散概念和规律提炼为物质、运动和相互作用、能量等总体观念。 |
| **模型与科学抽象** | 从实际对象中提取关键因素，形成质点、点电荷、电场线、磁感线、理想气体和天体轨道等模型，并通过适用条件和证据检验模型。 |
| **数学表示与理论推导** | 利用矢量、函数图像、微元或极限思想、守恒关系和数学推导描述规律，将定性认识发展为定量关系，并建立不同知识领域之间的联系。 |
| **证据、推理与论证** | 依据实验数据、观察事实和已有理论进行分析、归纳、演绎与论证，评估证据可靠性，解释结论、发现误差并修正观点。 |
| **科学史与社会实践** | 通过伽利略、牛顿、电磁理论、相对论和量子理论等发展过程理解科学认识的演进，并在航天、能源、医疗、材料和信息技术中检验知识价值。 |

## 四、总结

2025 年修订课标以核心素养为主线，以三类课程提供共同基础与多样选择，以内容要求和模块学业要求落实教学，再以三级学业质量标准连接评价。其考察重点是学生能否在真实情境中建构模型、运用规律、组织证据、开展探究并承担相应的科学与社会责任。

学习评价应同时关注知识结构、情境理解、模型与推理、实验全过程、表达交流和价值判断。综合性和创新性来自问题的真实程度、知识联系、证据质量及自主探究程度，而不应简单转化为超出课标范围的繁难计算。
