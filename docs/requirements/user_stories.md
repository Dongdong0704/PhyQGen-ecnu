# PhyQGen：用户故事与验收标准

各故事按 INVEST 原则围绕用户目标组织，采用“角色—目标—价值”表述；验收场景采用 Given / When / Then，内部生成行为通过受控样例及执行记录验证。

## US-01：使用个人账号并保护私有题目

**用户故事：** 作为高中物理教师，我希望使用个人账号管理任务和题目，以便持续备课并保护自己的出题资料。


```gherkin
Scenario: 注册并使用个人账号
  Given 教师使用尚未注册的账号信息
  When 教师完成注册并登录
  Then 可查看本人基本资料、修改密码并退出登录
  And 改密后旧密码不能登录、新密码可以登录，退出后访问受保护功能须重新认证

Scenario: 拒绝无效账号操作
  Given 请求使用重复账号、错误登录凭据或禁用账号
  When 执行对应的注册、登录或受保护操作
  Then 系统拒绝操作并给出明确提示

Scenario: 拒绝越权访问
  Given 教师甲、乙各有私有任务和题目
  When 甲通过页面或直接请求访问、修改、删除或导出乙的资源
  Then 服务端根据认证身份和资源归属拒绝操作
  And 伪造用户标识或普通注册时指定管理员角色均不能取得相应权限
```

## US-02：按教学目标设置出题要求

**用户故事：** 作为高中物理教师，我希望指定教学目标、题型和其他生成选项，以便获得适合当前教学安排的习题。


```gherkin
Scenario: 提交完整要求
  Given 教师已填写知识点或命题要求，并选择高一至高三的年级及支持的题型等信息
  When 教师分别设置认知目标、目标难度、配图与知识库选项，并提交 1 道或多道任务
  Then 系统接受请求，完整保存这些选项及补充的情境、计算步骤等约束
  And 认知目标支持记忆、理解、应用、分析，目标难度支持基础、中等、困难，两者分别记录

Scenario: 拦截无效要求
  Given 请求缺少必填项、含非法枚举值，或生成数量不是 1～5 的整数
  When 教师提交请求，包括绕过页面直接提交
  Then 前后端均校验适用字段，服务端拒绝无效请求并指出具体字段
  And 系统不创建生成任务
```

## US-03：跟踪单题与批量生成结果

**用户故事：** 作为需要集中备课的教师，我希望一次生成多道题并查看逐题进度，以便安排等待时间并保留已完成的成果。


```gherkin
Scenario: 查看异步任务进度
  Given 教师提交有效的单题或批量要求
  When 系统创建任务并异步执行
  Then 教师可查看任务标识、当前阶段、尝试轮次和逐题进度，界面仍可操作
  And 系统按依赖关系及并发上限执行，各题分别记录结果和版本

Scenario: 批量任务部分失败
  Given 5 道题中有题目生成失败，其余题目仍可继续处理
  When 全部题目处理结束且至少一份可用草稿保存成功
  Then 任务标记完成，成功草稿保留，失败题目显示错误摘要
  And 汇总展示实际草稿数量、逐题异常和教师确认状态，不以任务完成替代教师确认

Scenario: 没有草稿保存成功
  Given 单题或批量任务已全部处理结束
  When 未形成可用草稿，或所有可用草稿均保存失败
  Then 任务标记失败并显示具体原因，保存失败时保留当前可用内容
  And 系统不以占位题目或虚假保存成功补足请求数量
```

## US-04：参考知识库并查看实际来源

**用户故事：** 作为重视命题依据的教师，我希望选择知识库增强并查看引用来源，以便核对知识范围和教学要求。


```gherkin
Scenario: 使用检索证据命题
  Given 知识库可用且教师启用增强
  When 系统按知识点、年级、题型和认知目标检索到相关资料
  Then 证据在文本生成前进入命题上下文
  And 教师可查看题目实际引用的来源，系统保留片段标识、索引版本及题目版本关联

Scenario: 未使用知识库仍可生成
  Given 教师关闭增强，或检索未命中、检索服务异常
  When 系统处理出题请求
  Then 系统明确记录未使用知识库及具体原因，并按普通生成流程继续
  And 界面展示知识库可用状态，不虚构引用来源
```

## US-05：获得经过自动校验与修订的文本草稿

**用户故事：** 作为高中物理教师，我希望系统先检查并修订物理题中的常见错误，以便减少人工初审的重复核验工作。


```gherkin
Scenario: 生成完整文本
  Given 教师已提交有效要求
  When 命题智能体生成习题
  Then 实际生成和校验请求包含教学约束及可用证据，输出不直接复制参考原题
  And 草稿包含标题、教学属性、题干、答案、解析及适用的选项
  And 字段缺失或格式异常进入有限修复或失败流程，不使用占位内容

Scenario: 发现错误后自动修订
  Given 受控样题包含规律适用错误、条件缺失、单位或计算错误、歧义或答案解析矛盾
  When 文本校验智能体检查该版本
  Then 内部反馈记录问题位置和修订建议，并传回命题智能体修订后重新校验
  And 校验覆盖教学约束，选择题同时检查正确选项与干扰项
  And 反馈关联实际检查的版本，教师只收到草稿，不看到内部校验意见

Scenario: 达到上限或校验异常
  Given 默认单题最多 3 轮且包含首次生成，外部调用设有超时和有限重试
  When 达到轮次上限仍未通过，或发生超时、调用失败、校验输出无法解析
  Then 系统结束有限处理，保留可用草稿供教师直接审核和修改；无可用草稿则该题失败
  And 内部如实记录不通过或未完成等结论及原因，不默认通过；执行异常向教师提示
```

## US-06：获得与题干匹配的物理配图

**用户故事：** 作为需要图示题的教师，我希望配图准确表达题目情境和物理关系，以便学生据图理解和分析问题。


```gherkin
Scenario: 生成并校验实际配图
  Given 教师要求配图，命题智能体已提取实体、空间关系、参数、矢量及标注形成蓝图
  When 绘图智能体生成图片，且当前文本校验通过、图片就绪
  Then 图文校验智能体读取实际图片，核对实体、位置、方向、符号和数值
  And 图片、蓝图与题目版本对应，教师可预览实际配图

Scenario: 图文矛盾触发同步修订
  Given 受控样题的实际图片与题干存在方向、标注或数值矛盾
  When 图文校验发现问题
  Then 系统将配图问题反馈给绘图智能体，涉及题干与蓝图冲突时同步修订
  And 题设变更影响图示时更新蓝图和图片，再校验对应版本，不沿用旧版本结论

Scenario: 区分无需配图与配图异常
  Given 系统按教师的配图选项执行
  When 无需配图，或要求配图但图片生成失败、缺失、无法读取
  Then 无需配图时跳过绘图，内部图文结论为不适用
  And 配图异常时保留已有文本、提示配图异常，内部图文结论为未完成
```

## US-07：直接审核并修改习题

**用户故事：** 作为对课堂用题负责的教师，我希望清楚查看并直接修改草稿，以便独立核验物理正确性和教学适配性。


```gherkin
Scenario: 查看草稿并人工审核
  Given 系统已有保存成功的习题草稿
  When 教师打开详情并展开或隐藏答案解析
  Then 可查看题干、适用选项、答案、解析、配图、教学属性及实际引用来源
  And Markdown、LaTeX 和图片清晰可辨，状态显示待教师人工审核

Scenario: 保存教师修改
  Given 教师正在审核习题
  When 教师修改题干、选项、答案、解析或替换配图并保存
  Then 系统保存教师修改版本及修改时间，保留正确的图文关联
  And 教师可继续核验并确认，操作不新增智能体生成或自动校验调用
```

## US-08：确认定稿并保留版本记录

**用户故事：** 作为高中物理教师，我希望明确确认当前版本后再将其用于教学，以便区分草稿与定稿，并追溯确认责任。


```gherkin
Scenario: 人工确认形成定稿
  Given 教师已完成当前版本的人工审核和必要修改，必需内容完整、要求的配图可预览
  When 教师明确执行确认定稿
  Then 系统保存定稿及确认人、确认时间、确认版本，保存成功才显示教师已确认
  And 自动或手动暂存均不代替确认，确认过程不调用智能体

Scenario: 内容缺失或保存失败
  Given 当前版本缺少必需内容、要求的配图不可预览，或确认时保存失败
  When 教师执行确认定稿
  Then 系统提示具体原因，保留当前内容，不显示定稿成功
  And 教师补全内容或排除保存故障后再次确认，不触发自动校验

Scenario: 修改已确认题目
  Given 题目当前版本已由教师确认
  When 教师再次修改并保存
  Then 系统保存新版本并回到待教师人工审核，原确认记录仅对应原版本
  And 新版本由教师重新确认即可定稿，不沿用旧版本校验结论或重新调用智能体
```

## US-09：检索和整理个人题库

**用户故事：** 作为需要复用备课成果的教师，我希望快速查找和整理本人题目，以便减少重复出题。


```gherkin
Scenario: 查找本人题目
  Given 教师已有多道题目
  When 教师按标题或正文关键词搜索，按题型、知识点、认知目标、高阶思维能力、教师确认状态筛选
  Then 列表仅返回本人匹配题目，支持分页、按创建时间排序及详情查看

Scenario: 确认后删除题目
  Given 教师选中本人题目执行删除
  When 教师取消或确认删除
  Then 取消时保留题目，确认后题目不再出现在本人题库，关联图片、版本及记录不产生失效引用
  And 操作不影响其他题目及其他教师的资源
```

## US-10：导出已确认习题

**用户故事：** 作为准备课堂练习的教师，我希望导出已确认的单题或多道题，以便用于后续排版和教学。


```gherkin
Scenario: 导出确认版本
  Given 教师选中本人已确认的单题或多道定稿
  When 教师执行 TXT 导出
  Then 文件包含题干、适用选项、答案、解析、配图引用及教学属性，并保留公式源文本
  And 导出内容与对应的教师确认版本一致

Scenario: 选中尚未确认的版本
  Given 所选题目包含草稿或修改后尚未重新确认的当前版本
  When 教师尝试导出该版本
  Then 系统提示先完成教师确认，不将其作为定稿导出
```

## US-11：维护账号、知识库和生成配置

**用户故事：** 作为系统管理员，我希望维护必要的账号与生成资源，以便教师能够稳定使用出题流程。


```gherkin
Scenario: 维护服务与任务配置
  Given 管理员已通过身份及角色校验
  When 管理员维护账号状态、模型连接、并发数或重试上限
  Then 系统保存并按配置执行，记录操作者及时间，密钥保留在服务端
  And 禁用账号不能继续执行受保护操作，普通教师不能执行管理操作

Scenario: 维护可追溯知识库
  Given 管理员持有可合法使用的课标、教学资料或经典习题
  When 管理员构建或更新知识库索引
  Then 系统保留资料来源、片段标识和索引版本，并提供知识库可用状态
  And 建库维护与教师出题分离，已有题目的引用仍可追溯
```

## 跨故事验收

| 验收项 | 通过条件 |
| ----- | --- |
| 安全与隔离 | 受保护操作在服务端校验身份、角色和归属；密码哈希存储，上传和生成内容经过安全校验。 |
| 过程追溯 | 原始要求、模型配置、检索来源、图文版本、内部反馈及教师确认记录可关联；内部结论仅对应实际检查的系统生成版本。 |
| 质量与用时试评 | 拟邀请 3～5 名教师反馈，用不少于 30 道力学、电学样题覆盖文本、配图、单题与批量场景；按同一组要求与人工出题基线比较。记录物理错误、答案解析及图文一致性、教师初审可用率，以及生成、自动校验、人工审核修改和确认总耗时。合格阈值在试评后确定。 |

教师初审可用率为无需实质修改即可确认的草稿数占全部受评草稿数的比例；单题确认总耗时从配置要求起计至教师确认。
