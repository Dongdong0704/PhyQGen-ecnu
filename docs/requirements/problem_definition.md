# PhyQGen：5W1H 问题定义与产品描述

## 一、问题定义

**核心问题：** 在教师有限的备课时间内，如何生成符合高中物理教学要求、便于核验和修改的习题草稿，并减少物理逻辑错误、答案解析不一致与图文不符的风险？

| 维度 | 本项目的回答 |
| --- | --- |
| **What｜什么问题** | 编制物理题不能只让文字通顺：题设、物理模型、单位、计算、答案和解析必须自洽；图示题还需图文一致。生成式工具的草稿可能在这些环节出错。 |
| **Why｜为什么解决** | 手工编题与核验耗时；通用对话式生成缺少针对物理约束的固定检查流程，现成题库又难以按教学目标快速变式。教师需要可控的草稿与明确的审核入口。 |
| **Who｜谁受影响** | 核心用户是备课、组卷的高中物理教师；学生是题目使用者。首轮拟邀请 **3—5 名教师**参与访谈或原型反馈，人数是招募目标，并非已有用户。 |
| **Where｜在哪里发生** | 主要发生在课前备课、课后练习设计和题目修订环节；本项目当前处于**需求与设计期**，还不是部署使用期。 |
| **When｜何时最突出** | 当教师需要在短时间内生成指定知识点、题型或难度的变式题，尤其涉及多步骤推理、数值计算、单位换算或图示时，错误和核验成本更容易显现。 |
| **How｜如何判断改善** | 先建立人工编题基线，再用同一组需求比较草稿生成后的教师工作量与质量。首轮拟用不少于 **30 道**覆盖力学、电学等知识点的样题，记录物理错误、答案解析一致性、教师初审可用率及单题完成时间；具体合格阈值在试评后确定。 |

### 边界与原则

- 系统输出是**待教师人工审核的草稿**。智能体在生成过程中进行内部校验，并依据校验意见自动修订；教师直接审核和修改习题，完成后确认定稿，不再触发智能体自动校验。
- 项目需要完成知识库增强、文本习题与配图生成、智能体自动校验、教师人工审核与修改、确认定稿、保存和导出，并支持单题及批量生成。完整功能范围见[功能规格说明书](functional_spec.md)。
- 只使用可合法使用的课程标准和教学材料；题目来源、生成过程与修改记录应便于追溯。模型可能出错，质量判断需依赖人工复核。

## 二、产品描述

> PhyQGen 是面向高中物理教师的习题生成辅助工具，计划根据教师要求，结合知识检索生成文本与配图，由智能体内部校验并自动修订，再将习题草稿交给教师直接审核、修改和确认定稿。系统支持单题及批量生成，保留各题的生成依据、题目版本与教师确认记录，帮助教师减少重复编题与核验工作。

| 项目要素 | 初步设定 |
| --- | --- |
| **产品名称与类别** | PhyQGen；面向教师的高中物理习题设计辅助工具。 |
| **目标客户与规模** | 初期面向高中物理教师及教研组；计划先接触 3—5 名教师获取需求和原型反馈，正式用户规模待定。 |
| **核心价值** | 更快形成可修改的习题草稿；智能体自动校验物理逻辑与内容一致性，教师人工审核并决定是否定稿。节时与提质效果需要测试。 |
| **拟议方案** | 教师设置教学要求、数量及配图选项；系统按知识检索、文本与配图生成、智能体自动校验及反馈修订的顺序处理各题；教师人工审核、修改和确认后保存与导出。 |
| **相近方案与差异** | 通用对话工具便于快速起草，题库适合检索已有题目；本项目拟突出物理学科约束，实现题干与物理配图的协同生成及图文一致性校验，并支持教师直接修订习题。是否形成实际优势须经同任务对比。 |
| **团队背景** | 团队成员具有教育学与计算机的交叉背景，可结合教学需求分析、学科内容设计与软件开发开展项目。 |

### 验证顺序

1. 与目标教师核对真实编题流程、常见错误和可接受的审核时间。
2. 做低保真原型，确认输入字段、草稿展示与修改入口是否易用。
3. 用同一批需求比较人工流程与原型流程，覆盖文本题、配图题及批量生成，记录质量和用时；依据结果修正生成与审核流程，并复测。
