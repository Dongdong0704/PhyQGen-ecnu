# PhyQGen：软件系统功能规格说明书

本版围绕教师出题流程，完成需求配置、知识库增强、文本习题生成、物理配图、智能体自动校验、教师人工审核与修改、确认定稿、保存和导出，支持单题及批量生成。系统处于需求与设计期，本文描述拟开发功能；图示暂留占位。

## 1. 系统角色 (Actor)

### 1.1 人类角色

| 角色 | 主要操作 |
| --- | --- |
| 教师 | 设置出题要求，查看生成的习题，直接进行人工审核、修改和确认定稿，保存、检索与导出本人题目 |
| 系统管理员 | 维护教师账号状态、模型连接、知识库索引及任务执行配置 |

高中学生是题目的使用者，本版系统操作主体为教师。

> **[图 1 待补：系统用例图]** 展示教师的需求配置、单题与批量生成、查看习题、人工审核、修改、确认定稿、保存与导出，以及管理员的必要维护用例。

### 1.2 系统外部角色

| 角色 | 提供的能力 |
| --- | --- |
| 大语言模型服务 | 生成习题文本，执行文本自动校验并返回问题与修订建议 |
| 嵌入模型服务 | 将知识资料和检索请求向量化，为语义检索提供支持 |
| 图像生成及多模态模型服务 | 生成物理配图，读取实际图像并执行图文自动校验 |

### 1.3 智能体角色 (Agent Roles)

| 编号 | 智能体 | 职责与输出 |
| --- | --- | --- |
| AG-1 | 命题设计智能体（Planner） | 依据教学约束及检索证据生成题干、选项、答案、解析，按需输出配图蓝图 |
| AG-2 | 配图绘制智能体（Generator） | 根据蓝图生成物理示意图或情境图，返回图片及版本关联 |
| AG-3 | 文本校验智能体（Reviewer1） | 自动检查物理逻辑、条件、计算及答案解析，将校验意见反馈给命题智能体用于修订 |
| AG-4 | 图文校验智能体（Reviewer2） | 自动检查实际图片与题干的一致性，将校验意见反馈给相关生成智能体用于修订 |

协调器在生成过程中调度智能体，管理反馈、重试和逐题结果。文本生成后，配图生成与文本自动校验可并行；文本自动校验通过且图片就绪后，执行图文自动校验。

### 1.4 自动校验与人工审核的职责边界

本文使用**智能体自动校验**指生成过程中的内部检查，使用**教师人工审核**指教师直接检查、修改习题并决定是否定稿。校验意见仅用于智能体间的反馈修订；生成结束后向教师提供习题草稿，教师人工审核和修改后直接确认定稿，不再进入智能体校验环节。

| 环节 | 执行者与时点 | 检查重点 | 输出及效力 |
| --- | --- | --- | --- |
| 智能体自动校验 | 校验智能体；生成及系统自动修订期间 | 文本物理逻辑、计算与图文一致性 | 内部校验意见，用于自动修订；完成后输出习题草稿 |
| 教师人工审核 | 教师；收到习题草稿后 | 核验题目正确性、配图准确性及教学适配性 | 直接修改习题并确认；确认后形成定稿 |

## 2. 功能树 (Feature Tree)

### 2.1 出题需求配置模块

- **FR-1.1** 教师输入知识点或命题要求，选择高一至高三、单选题／多选题／填空题／简答题等多种题型，并设置是否配图及是否启用知识库增强。
- **FR-1.2** 支持记忆、理解、应用、分析多种认知目标，以及基础／中等／困难的目标难度；两者分别记录，并连同情境、计算步骤等约束传入生成与自动校验环节。
- **FR-1.3** 支持每次生成 1～5 道，1 道为单题任务，多道为批量任务；前后端均校验必填项、枚举值和数量范围，错误时指出具体字段。

### 2.2 任务创建与批量编排模块

- **FR-2.1** 提交后创建任务标识，保存原始要求并异步执行；批量任务为每道题分别记录执行结果、题目版本及内部校验反馈。
- **FR-2.2** 按依赖关系调度知识检索、文本生成、配图及自动校验；不同题目采用受限并发，单题失败不终止其余题目。
- **FR-2.3** 展示当前执行阶段、尝试轮次、逐题进度和错误摘要；阶段包括待处理、知识检索、文本生成、配图生成、自动校验、任务完成和任务失败。
- **FR-2.4** 展示逐题草稿、产出数量、生成异常及教师确认状态。全部题目处理结束后，至少一份可用草稿保存成功则任务完成，否则任务失败；部分失败时保留其余结果。任务完成表示草稿已暂存，仍需教师人工审核和确认。

### 2.3 知识库构建与检索增强模块

- **FR-3.1** 使用可合法使用的物理课标、教学资料和经典习题构建知识库，保留来源、片段标识及索引版本；建库维护与教师出题操作分离。
- **FR-3.2** 启用知识库增强时，在文本生成前按知识点、年级、题型及认知目标检索资料；相关证据进入命题上下文，并可查看本次实际引用的来源。
- **FR-3.3** 展示知识库可用状态；关闭增强、无匹配证据或检索异常时，明确记录未使用知识库及原因，再按普通生成流程执行。

### 2.4 文本习题生成模块

- **FR-4.1** 命题智能体结合教学约束与可用检索证据，输出标题、知识点、年级、题型、认知目标、目标难度、题干、选项（适用时）、答案及解析，避免直接复制参考原题。
- **FR-4.2** 校验输出结构与必需字段；缺失或格式异常时进入有限修复或失败流程，不以占位题目替代真实结果。

### 2.5 物理配图生成模块

- **FR-5.1** 需要配图时，命题智能体从题干提取实体、空间关系、物理参数、矢量及标注，形成配图蓝图，再交给绘图智能体生成实际图片。
- **FR-5.2** 保存图片、蓝图及对应题目版本，确保当前题干与配图关联正确；生成过程中自动修订题设且影响图示时，同步更新蓝图并重新生成或替换配图。
- **FR-5.3** 无需配图时跳过绘图；要求配图但生成失败、图片缺失或无法读取时，保留已生成文本并明确提示配图异常，不能按无需配图处理。

### 2.6 智能体自动校验与反馈修订模块

- **FR-6.1** 文本校验智能体检查物理规律及适用条件、单位与计算、条件完整性、表述歧义、答案解析一致性及教学约束；选择题同时检查正确选项与干扰项。
- **FR-6.2** 图文校验智能体读取实际图片，核对实体、位置、方向、符号及数值与题干是否一致；无需配图时标为不适用，配图异常时标为未完成。
- **FR-6.3** 校验智能体产生内部反馈，记录文本与图文结论、对应版本、问题位置及修订建议，用于智能体之间的反馈修订，不向教师展示。结论区分通过、不通过、未完成和不适用，未完成时记录原因。
- **FR-6.4** 文本问题反馈给命题智能体，配图问题反馈给绘图智能体；涉及题干与蓝图冲突时同步修订文本和配图。每轮系统自动修订后重新校验，默认单题最多 3 轮（含首次生成）；修订完成后向教师提供习题草稿。达到上限时保留可用草稿供教师直接审核和修改，未解决问题仅作内部记录，不向教师展示校验意见。
- **FR-6.5** 模型超时、调用失败或校验输出无法解析时，内部记录未完成或执行失败，向教师提示生成异常，不生成默认通过结论。已有可用草稿时保留草稿供教师直接审核和修改；未形成可用草稿时标记该题失败，不影响批量任务中其他题目的输出。

### 2.7 教师人工审核、修改与定稿模块

- **FR-7.1** 向教师展示生成的题干、选项、答案、解析、配图、教学属性及引用来源；支持 Markdown 与 LaTeX 预览，答案解析可展开或隐藏，并显示教师处理状态。
- **FR-7.2** 教师直接审核习题，独立核验物理正确性、条件与答案一致性、配图准确性及教学适配性，按需修改题目内容。
- **FR-7.3** 教师可修改题干、选项、答案、解析并替换配图，保存修改后的版本和修改时间；修改后由教师核验并直接确认，不再触发智能体生成或自动校验。
- **FR-7.4** 教师完成审核与修改后，明确执行“确认定稿”，记录确认人、时间及版本。系统仅检查必需字段和配图可预览等基本保存条件，不调用智能体；必需内容缺失或要求的配图无法正常预览时，阻止定稿并提示补全，补全后由教师再次确认。
- **FR-7.5** 已确认题目再次修改时，保存新版本并回到待教师人工审核状态；原确认记录仅对应原版本，新版本由教师重新确认即可定稿，不回到智能体处理流程。

### 2.8 题目保存、管理与导出模块

- **FR-8.1** 自动或手动暂存仅保存草稿及检索来源、图文版本；内部校验反馈关联其对应的系统生成版本。教师确认后保存定稿及确认记录，保存失败时不得显示成功。
- **FR-8.2** 个人题库支持分页、标题／正文关键词搜索、按题型、知识点、认知目标及教师确认状态筛选、按创建时间排序和详情查看；删除前确认，并处理关联图片、版本及记录。
- **FR-8.3** 支持将已确认单题或选中的多道定稿导出为 TXT，包含题干、选项、答案、解析、配图引用及教学属性，保留公式源文本；导出内容与教师确认的版本一致。

### 2.9 账户与必要系统维护模块

- **FR-9.1** 支持教师注册、登录、退出、基本资料查看与密码修改；凭据错误或账号重复时给出明确提示。
- **FR-9.2** 服务端根据认证身份校验角色及资源归属，教师只处理本人私有任务与题目；普通注册不能自行取得管理员权限，禁用账号不能执行受保护操作。
- **FR-9.3** 管理员维护教师账号状态、模型连接、知识库索引、并发数与重试上限等必要配置；密钥保存在服务端，管理操作记录操作者及时间。

## 3. 非功能需求 (Non-Functional Requirements)

| 编号 | 类别 | 需求描述 |
| --- | --- | --- |
| NFR-1 | 内容质量 | 生成内容应满足物理正确、条件完整、答案解析一致及教学要求；有配图时满足图文一致。定稿必须由教师人工审核并确认。 |
| NFR-2 | 身份与隔离 | 受保护接口校验身份、角色和资源归属，不信任客户端提交的用户 ID；密码采用哈希存储，上传内容和生成内容经过安全校验。 |
| NFR-3 | 响应与可靠性 | 长任务异步执行，界面可继续操作；外部调用设置超时与有限重试。单题异常与保存失败均可定位，并保留可用草稿。 |
| NFR-4 | 可追溯性 | 原始要求、模型配置、检索来源、图文版本、内部校验反馈及教师确认记录可关联追溯。内部校验结论仅对应其实际检查的系统生成版本，不能作为教师修改后版本的校验结论。 |
| NFR-5 | 易用性 | 界面区分系统生成进度与教师处理状态，不使用“已审核”等无法判断执行者的状态文案。教师直接查看和修改习题；公式、图片和编辑预览清晰可辨。 |
| NFR-6 | 可维护性 | 检索、文本生成、绘图、自动校验和题目管理职责分离，模型连接、并发数及重试上限可配置。 |
| NFR-7 | 验证与性能 | 分别记录系统生成与自动校验耗时、教师人工审核与修改耗时、确认总耗时；以同一组要求比较人工出题与系统辅助出题，合格阈值在试评后确定。 |

## 4. 典型业务流程（摘要）

### 4.1 完整出题流程

1. 教师登录并设置年级、知识点、题型、认知目标、难度、生成数量、知识库与配图选项；系统校验参数并创建任务（FR-1.1～1.3、FR-2.1）。
2. 协调器为每道题执行同一流程；启用知识库增强时先检索资料，记录使用来源或未使用原因（FR-2.2、FR-3.1～3.3）。
3. 命题智能体生成完整文本草稿，需要配图时同时提供蓝图；绘图智能体生成图片，并可与文本自动校验并行（FR-4.1～4.2、FR-5.1～5.3）。
4. 文本自动校验通过且图片就绪后，执行图文自动校验；出现问题时由相应智能体自动修订并重新校验。意见仅用于系统内部修订；达到上限或发生异常时保留可用草稿，没有可用草稿则标记该题失败（FR-6.1～6.5）。
5. 系统暂存可用的习题草稿，展示逐题结果和批量汇总，已产出的草稿进入待教师人工审核状态（FR-2.4、FR-8.1）。
6. 教师直接审核习题并按需修改，核验当前内容后确认定稿；不再触发智能体生成或自动校验（FR-7.1～7.5）。
7. 系统保存教师确认的定稿及确认记录；教师可从个人题库检索并导出已确认题目（FR-8.1～8.3）。

> **[图 2 待补：出题活动图]** 按上述顺序绘制，区分系统生成与教师处理两个泳道。反馈修订回路仅位于系统生成阶段；教师人工审核与修改后直接确认定稿，再进入保存与导出。

### 4.2 状态及返回路径

| 状态维度 | 主要状态 | 含义 |
| --- | --- | --- |
| 任务执行阶段 | 待处理、检索、生成、自动校验、完成、失败 | 全部题目处理结束后，有可用草稿保存成功则任务完成，否则失败；逐题结果分别记录 |
| 内部自动校验结论 | 通过、不通过、未完成、不适用 | 针对系统生成版本记录文本及图文结论，仅用于内部修订与追溯 |
| 教师处理状态 | 待教师人工审核、教师修改中、教师已确认 | 只有教师确认可形成定稿；修改定稿后返回待人工审核 |

自动校验不通过时，仅在系统生成阶段返回相应智能体修订；达到上限或服务异常时，保留可用草稿与真实内部结论，不以任务完成代替自动校验通过。草稿交教师人工审核后，教师修改并直接确认定稿，不返回生成或自动校验环节。批量任务中的题目分别处理和确认，不因其他题目失败而丢失结果。

## 5. 领域模型 (Domain Model UML)

> **[图 3 待补：领域模型类图]** 表示任务、题目版本、配图、检索证据、内部校验反馈和教师确认记录；内部反馈关联系统生成版本，确认记录关联教师最终确认的版本。

| 实体 | 核心属性 | 主要关系 |
| --- | --- | --- |
| User（用户） | 标识、角色、账号状态 | 拥有任务与题目，执行教师人工审核及确认 |
| GenerationTask（生成任务） | 原始要求、请求数量、执行阶段、逐题结果、模型配置、错误摘要 | 属于用户，产生一个或多个题目 |
| Question（题目） | 知识点、年级、题型、认知目标、目标难度、配图要求、当前版本、教师处理状态 | 属于用户及任务，包含多个版本 |
| QuestionVersion（题目版本） | 版本号、题干、选项、答案、解析、生成或修改时间 | 关联配图及检索证据；系统生成版本关联内部反馈，确认版本关联教师确认记录 |
| KnowledgeEvidence（检索证据） | 来源、片段标识、索引版本、引用内容 | 被生成任务及题目版本引用 |
| Illustration（配图） | 图片地址、生成蓝图（适用时）、版本关联 | 属于题目版本；系统生成的配图参与图文自动校验，教师可手动替换 |
| AutoCheckFeedback（内部校验反馈） | 校验类型、结论、问题位置、修订建议、时间 | 由校验智能体产生，关联实际检查的系统生成版本，不向教师展示 |
| TeacherConfirmation（教师确认记录） | 教师标识、版本、确认时间 | 记录教师对具体习题版本的定稿确认 |

## 6. 验收标准（摘要）

| 编号 | 验收场景 | 通过条件 | 对应需求 |
| --- | --- | --- | --- |
| AC-1 | 配置与批量执行 | 非法输入被拦截；1 道与 5 道任务均有逐题结果；单题失败不终止其余题目，草稿产出数量及教师确认状态准确展示；全部题目处理结束后按草稿保存结果判断任务完成或失败 | FR-1.1～1.3、FR-2.1～2.4 |
| AC-2 | 知识检索与文本生成 | 使用证据时可查看实际来源；关闭、未命中或异常时记录原因；完整生成题干、答案及解析，实际请求包含教师要求，无占位题目 | FR-3.1～3.3、FR-4.1～4.2 |
| AC-3 | 配图与图文自动校验 | 图片与蓝图及版本对应；预置图文矛盾产生内部反馈并触发修订；要求配图但图片缺失时提示配图异常并保留已有文本，内部结论不误记为通过；无需配图时内部结论为不适用 | FR-5.1～5.3、FR-6.2～6.4 |
| AC-4 | 文本自动校验与修订 | 用计算错误、条件缺失、答案解析矛盾等样题验证，内部反馈指出问题并传回生成智能体；修订后重新校验，再向教师提供习题草稿，不展示校验意见；达到上限时保留可用草稿供教师直接修改，内部结论如实保留 | FR-6.1、FR-6.3～6.4 |
| AC-5 | 故障与保存 | 模拟模型超时、无效输出及保存失败，显示真实错误并保留可用结果；未出现默认通过或虚假保存成功 | FR-6.5、FR-8.1、NFR-3 |
| AC-6 | 教师人工审核与版本 | 教师直接查看和修改习题，确认后才定稿；编辑及确认操作不新增智能体生成或校验调用。修改定稿后须确认新版本，旧记录只关联原版本；必需内容缺失或要求的配图不可预览时阻止定稿并提示补全，不调用智能体 | FR-7.1～7.5、NFR-4～5 |
| AC-7 | 身份、题库与导出 | 不同教师不能操作对方私有资源；本人检索、筛选、删除正确；单题及多题导出均与确认版本一致，包含配图引用 | FR-8.1～8.3、FR-9.1～9.3、NFR-2 |
| AC-8 | 质量与用时试评 | 拟评审不少于 30 道力学、电学样题，覆盖文本、配图、单题及批量任务，记录物理错误、答案解析及图文一致性、教师初审可用率和各环节耗时，与人工基线比较 | NFR-1、NFR-7 |

AC-8 中，教师初审可用率是无需实质修改即可确认的草稿数占全部受评草稿数的比例；单题完成时间从配置要求起计至教师确认，包含系统生成、自动校验与教师人工审核修改时间。阈值在试评后确定。
